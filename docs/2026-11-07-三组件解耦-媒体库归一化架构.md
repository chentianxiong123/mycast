# MyCast 三组件解耦架构：搜索 / 嗅探 / 媒体库归一化

> 日期：2026-11-07
> 背景：用户要求「多划分几个组件出来」——搜索、嗅探、媒体库三组件。之前专注搜索，未来归一化学媒体库。真正播放/投屏才上嗅探+投屏。

---

## 1. 目标

把当前散落的包整理成**三个职责清晰的组件**，以**媒体库为归一化核心**：

```
┌──────────┐   ┌──────────┐   ┌──────────────┐
│ 搜索组件   │→ │ 嗅探组件   │→ │ 媒体库组件     │
│ (search) │  │ (sniff)   │  │ (medialib 归一化)│
│ 找盗版站  │  │ 提取集数+  │  │ 播放/投屏       │
│          │  │ 拿流      │  │ (B站/盗版/本地)  │
└──────────┘  └──────────┘  └──────────────┘
   已做好         已做好        未来归一化核心
```

**关键转变**：搜索/嗅探是「找资源」的前置，**真正播放/投屏全部走媒体库**（归一化），不再散调。

## 3. 组件边界（职责 + 接口）

### 3.1 搜索组件 `search`
- **职责**：爬真实搜索引擎（bing/360/百度）找盗版站；过滤正版平台（`IsLegitSite`）。
- **能力**：`Search(ctx, query) []Result`、`ParseRendered(html, url, engine)`（WebView/Chrome 渲染后解析）、`RenderWithChrome`（桌面兜底）。
- **依赖**：无（叶子）。输出 `Result{Engine, Title, URL}`。

### 3.2 嗅探组件 `sniff`
- **职责**：从详情页提取集数（`ExtractURL`）+ 从播放页拿流（`ResolveStream`：m3u8/mp4/混淆解码）。
- **能力**：`ExtractURL(rawURL) []Episode`、`ResolveStream(playURL) (streamURL, mime)`、`NeedsBrowser(html)`（JS 挑战检测）。
- **依赖**：无（叶子）。输出 `Episode{Index, Title, PlayURL}` / `streamURL`。

### 3.3 媒体库组件 `medialib`（新建，归一化核心）
- **职责**：各种播放源（B站/盗版站/本地）→ 统一抽象 → 投屏。**播放/投屏只此一处**。
- **现在分散在**：`relay`（编排）+ `media`（重封装）+ `bili`（B站）。
- **目标抽象**：
  ```go
  type Source interface {
      Name() string                 // 源名（B站/盗版站/本地）
      Resolve(ctx) (*Stream, error) // 拿可播放流（含防盗链头）
      Cast(ctx, tvAddr) error       // 投屏到电视
  }
  type Stream struct {
      URL    string
      Mime   string
      Headers map[string]string // Referer/UA 透传（防盗链）
      Renew  func() error       // URL 到期续期（B站 deadline→403）
  }
  ```
- **归一化收益**：`relay.CastStream`/`bili`/`media` 播放逻辑收敛；server 只调 `medialib.Cast(source)`，不再散调 3 包。

## 4. 推进步骤（不推倒重来，渐进收敛）

| 步骤 | 做什么 | 产出 | 状态 |
|------|--------|------|------|
| 1 | **文档化边界**（本文档） | 三组件职责+接口+依赖图 | ✅ |
| 2 | **建 medialib 包**：定义 `Source`/`Stream` 接口 + 空实现 | `go/internal/medialib/`（4 单测过） | ✅ |
| 3 | **收敛 relay**：`PirateSource` 实现 medialib.Source（盗版站源，拿流+投屏） | `relay/pirate.go`（CastWith 返回流） | ✅ |
| 5 | **server 改造**：`/api/cast` 用 PirateSource.CastWith，不再散调 sniff+relay | 端到端 vipjuji 拿 m3u8 投屏 ✅ | ✅ |
| 6 | **mcp 验证**：已通过接口解耦（Searcher/Sniffer/Caster），满足组件边界；直链场景保留 | 可选后续对齐 medialib.Source | ⚠️ |
| 4 | **收敛 bili**：B站续期/playurl 实现 medialib.Source（B站源） | 待做 | ⏳ |

**边界原则**：
- `search`/`sniff` 保持叶子（不依赖媒体库）
- `medialib` 依赖 `relay`/`media`/`bili`（收敛方向）
- `server`/`mcp` 只调 `search`+`sniff`+`medialib` 三组件入口
