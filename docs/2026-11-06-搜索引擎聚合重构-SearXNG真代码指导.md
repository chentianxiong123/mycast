## ① 目标与动机

mycast 的搜索 MCP（`search_pirate`）是「老人一句话投屏」的入口。当前三引擎（bing/360/百度）聚合存在硬伤：

1. **360/百度 title 为空**（UI 只显示 URL，AI 无法识别剧名）
2. **360 拿不到结果**（请求会 302 的 www 版、不跟随、解析移动版特征不匹配）
3. **百度易误判验证码**（把页面 `loginUrlPrefix` 的 wappass 当验证码）
4. **bing 间歇性 400**（IP 级反爬，环境问题）

**根本原因**：mycast 手写正则解析搜索引擎 HTML，脆弱且漏标题。**正确做法是学 SearXNG 官方引擎实现**——它是成熟开源项目，每个引擎都有一套经过验证的解析策略。

最终目标：**三引擎都能拿到 `title + url + content`，聚合去重，稳定出盗版站**。

**核心解析策略（要学的 3 点）**：

### 2.1 Bing（bing.py）
- 请求：`https://www.bing.com/search?q=&adlt=`
- 解析：`//ol[@id="b_results"]/li[contains(@class,"b_algo")]` → `.//h2/a`
- URL 解码：`/ck/a?u=a1<base64url>` → base64url 解码（**mycast 已实现**）
- 标题：`extract_text(link)`；内容：`.//p` 去装饰图标

### 2.2 360（360search.py）—— mycast 最大差距
- 请求：`https://www.so.com/s?pn=&q=`（**PC 版，不是 m.so.com**）
- cookie：`get_cookie()` 从响应头 `set-cookie` 提取，**缓存 1 小时**（EngineCache）
- **关键**：`params['headers'] = {'Cookie': cookie}`（360 必须带 cookie 才回结果）
- 解析：`//li[contains(@class,"res-list")]` → `.//h3[contains(@class,"res-title")]/a`
  - URL：`@data-mdurl`（兜底 `@href`）
  - **标题：`extract_text(h3/a)`**（mycast 漏了标题）
  - 内容：`.//p[@class="res-desc"]` 或 `.//span[@class="res-list-summary"]`
- 空响应：非中国 IP 返回空 → 需兜底

### 2.3 百度（baidu.py）—— mycast 该换 JSON 接口
- 请求：`https://www.baidu.com/s?wd=&rn=10&pn=&tn=json`（**JSON 接口**，非移动版 HTML）
- cookie 预热：`https://image.baidu.com/` 拿 cookie（**这是过验证码的关键**）
- 验证码检测：`wappass.baidu.com/static/captcha` 出现在 **`Location` 响应头**（不是 body）
- 反爬：`data.antiFlag == 1` → AccessDenied
- 解析：`data.feed.entry[]` → 每项 `title` / `url` / `abs`（内容）
  - `title = unescape(entry.title)`、`content = unescape(entry.get("abs"))`

### 2.4 通用（utils.py / network）
- `eval_xpath` / `extract_text`：XPath + 文本提取（Go 用 `x/net/html` 遍历等价）
- `allow_redirects=False`：引擎自己判断 Location（验证码/跳转），不盲目跟随

## ④ 成功路径（重写后应达到）

对关键词 `q`，三引擎各自返回 `[]Result{Engine, Title, URL, Content}`：

```
1. Bing：www.bing.com/search?q= → li.b_algo/h2/a → title+url（base64解码）
2. 360：www.so.com/s?q=（带cookie）→ li.res-list/h3.res-title/a → title+data-mdurl
3. 百度：www.baidu.com/s?wd=&tn=json（cookie预热）→ feed.entry[] → title+url+abs
→ Search() 聚合：跑完三引擎、URL去重、isLegitSite过滤正版站、限N条
```

**验证命令**：
```bash
curl -s "http://127.0.0.1:8080/api/search?q=繁花" | python3 -m json.tool
# 期望：结果含 title（非空），engine 分布 bing/so/baidu 至少两三个
```

## ⑤ 踩坑记录（实测确认，非猜测）

| # | 现象 | 根因 | 解法 |
|---|------|------|------|
| 1 | 360 永远 0 结果 | 代码请求 `www.so.com/s` 不跟 302，实际跳到 `m.so.com`；且 `http.Client` 默认不跟随重定向 | 学 SearXNG：`www.so.com/s` + 手动 cookie + `allow_redirects=False` |
| 2 | 360/百度 title 空 | `reDataMdurl`/`reDataLog` 只抓 URL 属性，不抓标题文本 | 解析结果项容器（`h3.res-title/a` / `feed.entry.title`），标题必带 |
| 3 | 百度误判"安全验证" | `isCaptcha` 把页面里 `loginUrlPrefix=wappass...` 常量当验证码（实际是登录跳转配置） | 改判：只匹配 `wappass.baidu.com/static/captcha` 在 **Location 头** 或 body 真实验证码词 |
| 4 | bing 全域名 400 | `x-cache: CONFIG_NOCACHE`，IP 级反爬（CDN 拒绝该 IP/UA 组合） | 环境问题，代码修不了；靠 360/百度兜底，bing 失败自动跳过 |
| 5 | 百度移动版 `m.baidu.com` 200 但无真结果 | 页面是 JS 空壳（108 data-log 只有 1 个 `data-log="music"` 顶部导航），`data-log` 里 mu 稀少且无 title | 弃移动版 HTML，改 `tn=json` JSON 接口（SearXNG 正解） |
| 6 | `reDataLog` 只匹配双引号 | 百度移动版用单引号 `data-log='...'` | 兼容单双引号（已改） |

## ⑦ 决策记录

| 决策 | 选 A | 弃 B | 理由 |
|------|------|------|------|
| 百度解析方式 | **`tn=json` JSON 接口**（SearXNG 正解） | 移动版 `m.baidu.com/s` HTML 正则 | JSON 有 title/url/content，干净；之前弃用是因没加 cookie 预热导致验证码，加了就通 |
| 360 请求目标 | **`www.so.com/s` + cookie**（SearXNG 正解） | `m.so.com`（移动版） | SearXNG 证明 www+cookie 能通；m.so.com 是我之前绕开 302 的尝试，但漏标题 |
| 解析工具 | **XPath 语义（Go x/net/html 遍历）** | 手写正则 | 正则脆（引号/嵌套/属性顺序），XPath 语义精准定位 |
| cookie 处理 | **预热 + 缓存** | 每次请求都拉 | 减少反爬触发，SearXNG 用 EngineCache 缓存 1h |
| 聚合策略 | **跑完所有引擎 + 去重**（已改） | 有结果即 break | 之前 break 导致单引擎独占，360/百度永远测不到 |

## 附：参考 SearXNG 关键代码（直接抄策略）

**360search.py response**（解析 + 标题）：
```python
for item in dom.xpath('//li[contains(@class, "res-list")]'):
    title = extract_text(item.xpath('.//h3[contains(@class, "res-title")]/a'))
    url = extract_text(item.xpath('.//h3[contains(@class, "res-title")]/a/@data-mdurl'))
    if not url:
        url = extract_text(item.xpath('.//h3[contains(@class, "res-title")]/a/@href'))
    content = extract_text(item.xpath('.//p[@class="res-desc"]'))
    if title and url:
        results.append({"title": title, "url": url, "content": content})
```

**baidu.py response**（JSON）：
```python
data = json.loads(text, strict=False)
if data.get("antiFlag") == 1:
    raise SearxEngineAccessDeniedException(...)
for entry in data["feed"]["entry"]:
    title = unescape(entry["title"])
    content = unescape(entry.get("abs", ""))
    results.append({"title": title, "url": entry["url"], "content": content})
```
