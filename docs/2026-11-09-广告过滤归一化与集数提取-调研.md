# 广告过滤 / 归一化 / 集数提取 调研（2026-11-09）

> 目标：研究主流浏览器/搜索引擎/开源项目怎么**过滤广告 + 归一化 + 提取集数**，为 mycast 盗版站集数提取与去广告设计提供依据。
> 结论先行：**三件套 = ① 广告拦截（uBlock 过滤引擎）② 正文提取（Readability 启发式）③ 集数归一化（选择器/正则 + 去重排序）**。

---

## 1. 广告过滤：uBlock Origin（开源拦截标杆）

**原理**（github.com/gorhill/uBlock wiki "Overview of network filtering engine"）：

| 层 | 机制 | 特点 |
|---|---|---|
| **静态过滤器** | 预编译规则，`||domain^`、`##.ad-class`、`#?#` 等 | 支持通配符、cosmetic filtering（**删 DOM 元素**），可加载社区规则列表 |
| **动态规则** | 运行时点选生成（`allow`/`block` 某个 URL） | 零开销，优先级高于静态 |
| **URL 动态规则** | 只匹配"URL 前缀" | 窄范围，诊断用 |

**关键**：
- **cosmetic filtering**（`##selector`）= **DOM 级删广告**（不是网络层）——**盗版站去广告最匹配**（广告是内嵌 div/iframe，非独立域名）
- 匹配引擎：**URL 模式 + 选择器**，内存开销大（编译全部规则）

**对我们**：盗版站广告多为**内嵌区块**（`##.ads`、`##[class*="ad-"]`、`<iframe src="...ad...">`），**cosmetic 思路**（DOM 删节点）比网络拦截更适合——但 mycast 是 **Go 正则**（无 DOM），所以**正则模拟 cosmetic**：匹配广告特征 class/id → 移除。

## 2. 正文提取：Mozilla Readability（去导航/广告/侧栏）

**原理**（mozilla/readability README + StackOverflow "What algorithm does Readability use"）：
- **DOM 启发式**，不是正则——**给候选节点打分**：
  - **文本密度**（`textLength / linkTextLength`）
  - **链接密度**（link 文本占比，高=导航/广告）
  - **标签权重**（`<p>`、`<pre>`、`<article>` 加分；`<nav>`、`<aside>`、`<footer>` 减分）
- 去掉 `class`/`id` 含 `nav`/`ad`/`comment`/`sidebar`/`footer` 的节点
- 候选节点按分数排，取最高，再清空子节点
- `charThreshold=500`（正文至少 500 字符才返回）

**关键**：Readability 用**特征打分**（文本密度 + 链接密度 + 标签名），不是死规则——**通用、适应任意站**。

**对我们**：mycast 集数提取是**容器+文字**（规则 v2）——可借鉴 Readability 的**链接密度**：集数区 = 链接密集 + 短文本（第X集），广告区 = 链接稀疏 + 长文本或图片。**集数区打分**（链接密度高 + 文本短 + 数字占比高）区分广告/导航。

## 3. 影视站集数提取：takdrama（盗版站开源项目）

**做法**（deepwiki.com/i1nam/takdrama）：
- 后端 Node/Express **Cheerio 选择器**（CSS 选择器，非正则）提取：
  - `/api/episodes`：`extractEpisodes(html)` → `[{href, number}]`（**集数 + 链接**）
  - 选择器：`<div class="content_episode">` 容器 + `<a class="cona" href>第X集</a>`
- **去广告**：自定义接口，绕过原站重广告（保留 m3u8 流）
- **HLS 代理**：`/api/proxy` 改写 manifest 绕过 **CORS + Referer**（和 mycast 一样）

**关键**：盗版站集数 = **容器选择器 + 链接 + 集数**。takdrama 用 **Cheerio（CSS 选择器）**，mycast 用 **正则**——两者都能提，但**选择器更抗页面结构变化**（按语义 class），正则更轻（无 DOM）。

## 4. 归一化设计（mycast 适用）

盗版站集数提取 + 去广告，**归一化流程**：

```
HTML（详情页）
  → 去广告：正则删广告特征块（class/id 含 ad/adv/promo/banner/gg/guanggao 等，<iframe 广告，弹窗 fixed）
  → 候选容器：找集数容器（class/id 含 ep/episode/playlist/juji/list）
  → 集数项：<a> 文本匹配 /第?\s*\d+\s*集?/ 或 /\d{1,3}/ 且 href 含 mp4/m3u8/播放页
  → 归一化：去重（by href），排序（by 集数数字），去空
  → 输出：[{n, title, href}]
```

**广告特征（正则）**：`class|id` 含 `ad|adv|promo|banner|gg|guang|ggg|top_ad|side_ad`，`<iframe.*(ad|gg|advert)`，`style="position:fixed"` 弹窗。

**集数特征**：`第\d+集` / `\d+-\d+集` / `(\d+)` 数字 + 短文本（<30 字符）+ 链接密集区。

**打分归一化**（借鉴 Readability）：
- 候选节点评分 = `链接密度 × 集数文本占比 × (1 - 广告特征)`
- 链接密度 = 集数链接数 / 总链接数
- 集数文本占比 = 匹配 `/第\d+集/` 的文本 / 总文本

## 5. 结论（三件套）

| 阶段 | 方法 | 借鉴 |
|---|---|---|
| **去广告** | 正则删广告特征块（cosmetic 思路） | uBlock cosmetic filtering |
| **提正文** | 候选容器打分（链接密度+集数文本占比） | Readability 启发式 |
| **归一化** | 去重 by href + 按集数数字排序 + 去空 | takdrama extractEpisodes |

**关键洞察**：
- 去广告 = **DOM 删除**（cosmetic），不是网络拦截（盗版站广告内嵌）
- 提集数 = **候选打分**（链接密度），不是死规则（通用）
- 集数 = **href + 数字**（number），排序去重
