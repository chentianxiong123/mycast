# 媒体库归一化与 OnScreen 移植探索（三组件解耦 + 内置播放器）

> 日期：2026-11-07
> 探索对象：MyCast 从"搜索→嗅探→投屏"链路，升级为"三组件解耦 + 媒体库 + 内置播放器"的流媒体聚合播放器
> 参照项目：`go-extractors/extractors`（Go yt-dlp 接口）、`OnScreen`（Go 媒体服务器 UI，ref-project 克隆）

---

## ① 目标与动机

MyCast 原先是"手机当 DLNA 中继投屏"（B站/盗版站 → 电视）。这轮要：
1. **三组件解耦**：搜索（找站）/ 嗅探（提取集数）/ 媒体库（归一化播放）三个清晰组件
2. **媒体库归一化**：B站/盗版站 → 统一 `medialib.Source` 接口（参照 go-extractors）
3. **媒体库 UI**：继续观看行 + 海报墙 + 详情浮层（移植 OnScreen UI 结构）
4. **内置播放器**：web 里本地能播（mp4/m3u8），不依赖投屏

**核心约束（用户定）**：媒体库**纯流媒体，永不产生文件/本地存**——只做流媒体源索引（历史/收藏），不学 OnScreen 的 PostgreSQL/刮削/本地文件库。

## ② 资源拓扑（最重要）

### 2.1 参照模型：OnScreen（ref-project 克隆）
```
/mnt/shared/ref-project/OnScreen（git clone --depth 1，235M）
├── cmd/server/          单二进制主程序（go build ./cmd/server）
├── internal/            Go 底层（几十包：domain/db/metadata/mediastore/streaming/artwork）
├── web/src/routes/      SvelteKit UI 页面
│   ├── +page.svelte     首页（1071行：ContinueWatching + Row/LibraryRow 海报行）
│   ├── series/[id]/     详情页（ItemDetail + ChildItem + assetUrl）
│   └── watch/           播放器
├── clients/             多端（Tauri desktop/Tizen/webOS/Android）
└── assets/              PostgreSQL + 刮削（TheMovieDB）
```
**关键 UI 模式**：首页 = `ContinueWatching`（继续观看大卡+进度）+ `Row`/`LibraryRow`（海报行网格）；详情 = `ItemDetail`（海报+简介+子项）+ `assetUrl(path)`（`/artwork/{path}?w=300` 海报 URL）。

### 2.2 参照模型：go-extractors（Go yt-dlp 接口）
```
Host.Resolve(url) → Instance    找源（按 URL 匹配 extractor）
Instance.Match(url) → Claim     站点匹配
Instance.Extract(ctx) → media.Media  拿流（metadata + formats）
Instance.List(ctx) → Playlist   播放列表（集数）
```
**插件模式**（每站独立可执行 + hashicorp/go-plugin）——mycast 不用插件机制，只学接口设计。

### 2.3 MyCast 三组件结构（解耦后）
```
go/internal/
├── search/     搜索组件（叶子：爬 bing/360/百度，Chrome 渲染兜底）
```

## ④ 成功路径（可复现步骤）

### 4.1 三组件解耦
1. `go/internal/medialib/medialib.go`：定义 `Source{Name/Resolve/Cast}` + `Stream{URL/Mime/Headers/Renew/Title}`（纯接口，不依赖实现方）
2. `relay/pirate.go`：`PirateSource` 实现 Source（`Resolve` 用 `sniff.ResolveStream` 拿流 + Referer 防盗链；`CastWith` 拿流+投屏+返回流）
3. `relay/bili_source.go`：`BiliSource` 实现 Source（`Resolve` 用 `bili.PlayURL`；`Cast` 走 `startRelayByCID`）
4. `server /api/cast` 改用 `PirateSource.CastWith`（不再散调 sniff+relay）

### 4.2 媒体库 UI
1. 新页 `page-library`（第 2 个 tab 🎬）+ CSS（`.row-scroll`/`.poster-card`/`.continue-card`）
2. `loadLibrary()`：`/api/library` → 继续观看行（前 3 大卡）+ 海报墙（横向滚动）
3. 详情浮层 `detail-overlay`：点海报 → `openDetail` → `loadDetail`（sniff 集数）→ 集数网格 → `selectDetailEp` 选中

### 4.3 真海报图 + 收藏
1. `sniff.ExtractPoster(html, base)`：og:image → img[cover/poster/data-src] 抓封面
2. `server.Library`：持久化 `library.json`（title/url/poster/source/time）
3. `/api/poster` 代理：带站点 Referer 转发封面（绕过防盗链）
4. 前端海报墙 `<img src="/api/poster?url=...">`

### 4.4 内置播放器
1. 下载 `hls.min.js` → `go:embed web/static/hls.min.js` → `/static/hls.min.js` 路由
2. 播放器浮层 `player-overlay`（全屏 `<video>`）
3. `playLocal(url, mime, title)`：m3u8 → `new Hls()`（hls.js），mp4 → 原生 `<video>`
4. 详情浮层「📱 本地播放」按钮 → `playEpLocal`（拿流→播放器）

## ⑤ 踩坑记录（最有价值）

| 现象 | 根因 | 解法 |
|------|------|------|
| **startRelayByCID 播 30 分钟卡顿** | NVA 投屏入口没接续期（只有主入口 startRelay 接了 `extractBiliKey→startBiliRenew`） | startRelayByCID 补 `extractBiliKey`+`startBiliRenew` |
| **`originOf("bad")` 返回 `"://"`** | `url.Parse("bad")` 成功但 Scheme/Host 空，拼接出 `://` | 检查 `u.Scheme=="" \|\| u.Host==""` 返回空 |
| **`PirateSource.Resolve` panic** | `Extract`/`PlayURL` 为 nil（测试没设） | Resolve 加防御：nil 检查 + 空 PlayURL 报错 |
| **`Library.Fav` 重复没置顶** | Time 格式到分钟（同分钟相同），`sort.SliceStable` 保持原序 | Fav 重复时移到头部（不依赖 Time 排序）；Time 用秒 |
| **`Library.save` 没写盘** | `dataDir/library.json` 父目录不存在，`os.WriteFile` 失败 | save 先 `os.MkdirAll(filepath.Dir(path))` |
| **封面图 404** | 站点封面 URL 本身失效（非代理问题） | 重嗅探拿新封面；代理逻辑正常 |
| **浏览器原生不播 m3u8** | Chrome 等不支持 HLS，需 hls.js | 内嵌 hls.js（go:embed），m3u8 用 `new Hls()` |

## ⑦ 决策记录（为什么选 A 不选 B）

| 决策 | 选 A | 不选 B | 原因 |
|------|------|--------|------|
| 参照模型 | **yt-dlp InfoExtractor**（go-extractors） | Stremio addon / Jellyfin | 每源统一 extractor 接口，正是"各种源→统一流" |
| 媒体库 UI | **OnScreen** | Jellyfin | Go 单二进制 + Web UI + 投屏，定位几乎一样 |
| OnScreen 存储 | **不学** | 照搬 PostgreSQL/刮削 | mycast 纯流媒体，不存文件/不刮削 |
| OnScreen 前端 | **纯 JS SPA 重写** | 照搬 SvelteKit/TS | mycast 零构建，SvelteKit 太重 |
| extractor 机制 | **进程内包**（medialib.Source） | hashicorp/go-plugin 插件模式 | 单二进制轻量，插件分发太重 |
| 本地文件 | **不放**（纯流媒体） | OnScreen 本地文件库 | 用户明确"纯流媒体" |
| m3u8 播放 | **内嵌 hls.js** | CDN 加载 | 局域网可能无外网，go:embed 离线可播 |
